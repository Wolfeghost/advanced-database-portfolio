======================================================================
R7 Failover readiness
======================================================================
retryWrites in connection string: true (driver default)
If the primary fails, the remaining two members (a majority) elect a new
primary, typically within ~10-12 seconds. With retryable writes the driver
re-sends an interrupted write once to the new primary, and writes made
with w:'majority' are never rolled back. A w:1 write that reached only the
old primary CAN be rolled back. (The free M0 tier cannot trigger a test
failover; see README section 4.)
